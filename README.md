# The Classic World

该仓库为“Minecraft”经典全景图拍摄地的世界文件

[!firstperson](/images/firstperson.png)
[!thirdperson](/images/thirdperson.png)

## 使用

进入 `.minecraft/versions/[version]/saves`，打开终端。

运行:
```bash
git clone https://github.com/isHuaMouRen/the-classic-world.git
```

打开你的游戏，即可进入该世界

## 说明

该世界从 `Beta 1.7.3` 升级至最新版 `26.2` ，因此只保留了在Beta1.7.3生成的原始区块。其余新生成的区块被剔除

周围被屏障包围，屏障范围 y = -1 ~ 62
